MC 02-01-2001 — Revised Customer Premises Equipment Interface Standards and Type Approval Procedures

Status
Active
Issued
2001-01-01

Pursuant to MC No. 1-04-88, promulgates revised Customer Premises Equipment (CPE) interface standards and type approval/type acceptance procedures, establishing the technical and administrative framework by which CPE connected to public telecommunications networks is evaluated for safety and interface compliance.

Type Approval and Type Acceptance

Type approval evaluates a CPE's conformance to national interface standards (per ITU-T/ITU-R recommendations) through laboratory testing to ensure end-user safety, network protection, and freedom from harmful spectrum interference; foreign-certified equipment may be accepted via manufacturer self-declaration or foreign test reports at NTC's discretion. Type acceptance applies where no established interface standard corresponds to a CPE's specifications, evaluated case-by-case on submitted foreign test reports and approval certifications.

Scope, Connection Standards, and Administrative Procedure

Type-approval is confined to interface parameters in Section III (covering electrical safety, EMC, network general requirements, and equipment-specific standards for corded/cordless telephones, PABX/KTS, CMTS terminals, fixed wireless access, paging, data communications equipment, answering machines, mobile satellite terminals, VSAT, and advanced CPEs). All single connections to the public switched telephone network must use standard USOC RJ11C jacks and plugs. Applicants file a type approval request with NTC or an accredited test laboratory, submitting equipment documentation, import clearances, and manufacturer's declaration of conformity; individual travelers' personal-use CPE may bypass type approval subject to interface approval testing by the serving network operator.
