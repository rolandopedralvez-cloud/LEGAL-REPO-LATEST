Memorandum Circular No. 03-06-2019 — Rules and Regulations on Mobile Number Portability

Status
Active
Issued
2019

Sets out the rules and definitions governing Mobile Number Portability (MNP) — the ability of a mobile postpaid or prepaid subscriber with no outstanding financial obligation to their Donor Provider to retain an existing mobile number when switching to another mobile service provider, or to change their subscription type between postpaid and prepaid.

Key Definitions

Defines the Cutover Period — the window during which a porting subscriber has no mobile service while porting completes, capped at four hours — along with the Donor Provider (the network the number is leaving), the Local Number Portability Database maintained by each Mobile Service Provider, Mobile Postpaid and Mobile Prepaid Subscriber, and the Mobile Number Portability Service Provider (MNPSP), the entity that provides the porting service infrastructure.
